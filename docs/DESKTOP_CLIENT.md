# デスクトップクライアント仕様

更新日: 2026-09-10

## 1. 対象と目的

初期版の正式対象はNixOS上のniri/Waylandとswayncである。デスクトップクライアントはUIを持たないユーザーセッション常駐CLIとし、相手側Androidからの要求への応答と、ローカル通知の相手側Androidへの転送だけを行う。デスクトップから撮影・状態更新などを要求する機能は持たせない。

Androidは各利用者側に1台とする。Linux端末はAndroidと同じ利用者側へ追加登録でき、将来は同じ通信コアをWindowsクライアントから利用できる構成にする。

## 2. プロセス構成

- 実装言語はGoとする。
- 認証、HTTPS API、WebSocket、再接続、設定読み込み、通知のレート制限を共通コアとする。
- 画面撮影とデスクトップ通知取得をOS固有アダプターとする。
- Linuxではsystemdユーザーサービスとして、WaylandおよびD-Busユーザーセッション内で実行する。
- 資格情報はパーミッション`0600`の状態ディレクトリへ保存し、設定ファイルやログには記録しない。

## 3. 登録と端末モデル

既存の`slot 1`と`slot 2`はペア内の「利用者側」を表す。管理CLIで既存ペアとslotを指定して単回利用の追加端末招待コードを発行する。

各端末は次の情報を持つ。

- 端末ID、表示名、利用者側
- プラットフォーム（`ANDROID`、`LINUX`、将来の`WINDOWS`、`IPAD`）
- 能力（通知送信、通知受信、画面撮影、状態共有）
- 個別の認証鍵とプッシュトークン
- 作成日時、最終接続日時、失効日時

管理CLIは追加招待、端末一覧、端末失効を提供する。Androidは1利用者側1台という運用制約を維持し、サーバーはLinuxなどの追加端末を同じslotへ登録できるようにする。

## 4. 通知転送

- Freedesktop Notifications仕様の`org.freedesktop.Notifications.Notify`呼び出しをユーザーセッションD-Bus上で監視する。
- アプリ名、summary、body、desktop-entry、通知時刻を取得する。
- Partner Watch自身の通知、空の通知、短時間の同一通知を除外する。
- 転送先は反対側の`notification.receive`能力を持つAndroid端末とする。同じ利用者側のAndroidやPCには送らない。
- 本文の上限、レート制限、1時間保持、FCMへ本文を載せない方針は`NOTIFICATION_FORWARDING.md`と共通とする。
- 通知本文のマークアップはプレーンテキストへ変換し、画像、操作、リンク先は転送しない。

初期版はniri環境で使用中のswayncとの共存を検証対象とする。D-Bus監視が利用できない環境では通知転送だけを無効化し、撮影待受は継続する。

## 5. 全ディスプレイ撮影

- niriが提供する`wlr-screencopy`を`grim`から使用する。
- 接続中の全出力を列挙し、出力ごとにJPEGを1枚生成する。
- ポインターは含めない。
- 1要求の結果は、出力名、幅、高さ、画像IDを持つ画像一覧とする。
- Androidでは画像を出力名付きの一覧として表示し、各画像を個別に写真コレクションへ保存できるようにする。
- 1画像は最大16メガピクセル、10 MiB、1要求は最大8画面とする。
- 画像はAndroidが取得した直後にサーバーから削除し、未取得でも1時間で削除する。
- 一部の出力だけ失敗した場合は成功画像を返し、すべて失敗した場合だけ要求全体を失敗とする。

Linux側の撮影受付は既定で無効とする。設定ファイルで有効化した後は、Androidのユーザー補助サービスに相当する追加の対話確認を毎回は行わない。これは端末所有者が常駐サービス設定時に明示的に同意する運用とする。

## 6. 設定

設定ファイルはXDG Base Directoryに従い、既定で`$XDG_CONFIG_HOME/partner-watch/config.toml`を使用する。

```toml
server_url = "https://example.com"
device_name = "My Linux PC"
accept_captures = false
forward_notifications = false
```

登録前だけ招待コードをCLI引数または対話入力で受け付ける。招待コードと端末資格情報を設定ファイルへ書き戻さない。

## 7. 今回含めないもの

- Linuxからの要求操作とGUI
- Linuxでの転送通知の表示
- バッテリー・現在地共有
- X11、GNOME、KDE、niri以外のWayland compositorの正式対応
- Windowsクライアント本体
- iPadクライアント
